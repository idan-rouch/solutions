Deprovision:
	SCIM-managed 	= Yes
	IdP Active 	= No
	1P Active 	= Yes 	→ deprovision() via SCIM (don’t touch unmanaged users here).

SCIM onboard (convert/attach, not create):
	SCIM-managed 	= No
	IdP Active 	= Yes
	1P Active 	= Yes 	→ scim_onboard() (bring under SCIM management; no duplicate account).

Provision (create):
	SCIM-managed 	= No
	IdP Active 	= Yes
	1P Active 	= No (or not found in 1P) 	→ provision() via SCIM (create the 1P account).

to_deprovision = SCIM-managed AND IdP inactive AND 1Password active

to_scim_onboard = not SCIM-managed AND IdP active AND 1Password active

to_provision = not in 1Password AND IdP active
(+ keep: in_1p_not_in_idp = in 1Password but not in IdP)
